### Facts & data

* **System requirements for DaVinci Resolve:**
  * **Minimum OS:** Windows 10/11, macOS 11+, or Linux.
  * **Minimum system RAM:** 16 GB (32 GB recommended for Fusion page and complex graphics).
  * **Minimum GPU VRAM:** 4 GB VRAM (8 GB VRAM for 1080p, 12 GB VRAM for 4K timeline resolution).
  * **Storage requirement:** Solid State Drive (SSD) required for media cache and database access.

### Agent research notes

* **DaVinci Resolve database and project architecture:**
  * DaVinci Resolve uses a database architecture rather than standalone `.drp` project files on disk for active editing.
  * Local project libraries rely on an internal SQLite database stored in application support directories.
  * Moving projects across computers requires explicit export as `.drp` (DaVinci Resolve Project) files or `.dra` project archives containing media.
  * Accessing local SQLite project databases over network shares (NAS) causes database corruption.

* **Keyframe animation mechanics:**
  * Edit page Inspector provides simple linear keyframing for `Transform` parameters (`Position`, `Pitch`, `Yaw`, `Zoom`).
  * Dynamic Zoom tool in the Edit page provides automated Ken Burns style framing without manual keyframes.
  * Fusion page `Transform` node connected to the `Spline` editor enables cubic bezier easing curves via the `F` shortcut key.
  * Complex screen recording animations (smooth easing zooms into UI elements) require Fusion node composition or third-party macros.

* **Color page non-video-professional basics:**
  * Primaries wheels manage tonal ranges: `Lift` (shadows), `Gamma` (midtones), `Gain` (highlights), `Offset` (global balance).
  * Recommended serial node order: `Node 1` (Color Space Transform / CST) -> `Node 2` (Primary balance) -> `Node 3` (Secondaries / Power windows) -> `Node 4` (Output LUT / Look).
  * Color Space Transform (CST) plugin normalizes camera log or display formats to target spaces like `Rec.709`.

* **Audio processing in Fairlight page:**
  * Channel strip order for voiceover cleanup: `Voice Isolation` -> `High-Pass Filter` (80-100Hz cut) -> `Parametric EQ` -> `Dynamics Compressor` -> `Limiter` (-4dB ceiling).
  * Studio edition AI Voice Isolation requires 60-70% wet mix to prevent artificial artifacts while stripping background noise.

* **Software feature demo workflow strategy:**
  * Capture lossless 4K screen footage using OBS Studio or ScreenFlow at native display resolution.
  * Import clips into DaVinci Resolve; assemble rough cut on the Cut or Edit page.
  * Apply smooth UI zoom callouts using Fusion page Spline curves or third-party macros.
  * Process narration audio in Fairlight using Voice Isolation and Dialogue Leveler.
  * Render MP4 H.264/H.265 using Web Optimized preset for fast browser playback.
