== Local setup

This project provides https://docs.docker.com/ai/sandboxes/configuration/environment-files/[Docker Sandbox environment files] for local development.

[source,sh]
----
sbx env exec .sbx/sbxenv.yaml -- bun run check:sbx-env
----

Users may append an optional host configuration layer, for example:

[source,sh]
----
sbx env exec .sbx/sbxenv.yaml ~/.local/share/sbx/personal/personal.sbxenv.yaml -- bun run check:sbx-env
----

Other literal command shapes for running:

[source,sh]
----
sbx env run .sbx/sbxenv.yaml
sbx env run .sbx/sbxenv.yaml ~/.local/share/sbx/personal/personal.sbxenv.yaml
----

For the AGY kit, substitute `.sbx/sbxenv.agy.yaml` to preserve its extra pinned agent-kit reference.
