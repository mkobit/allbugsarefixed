Wired into `src/pages/blog/[...slug].astro` right after `<Content />`. - [x] 3.2 Hydrate the click-wiring component with `client:visible` (matching the `abf-k7d.1` `TableOfContents.tsx` precedent) and verify the progressive-enhancement fallback: the image still renders normally if JS is disabled or hydration hasn't completed.
  Validation: manual check with browser JS disabled — image still displays inline at normal size, just not interactive.
