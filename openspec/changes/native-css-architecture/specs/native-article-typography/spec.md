## ADDED Requirements

### Requirement: Article prose styles use native cascade layers
Markdown content styling SHALL be defined in `src/styles/typography.css` within `@layer typography`.
Article containers SHALL use the class `.article-prose`.
The stylesheet SHALL provide a backward compatibility alias for `.prose` during transition.

#### Scenario: Rendering an article with native typography styles
- **WHEN** an article page renders markdown content inside `.article-prose`
- **THEN** typography styles from `@layer typography` format the article elements

### Requirement: Prose element styling maintains flat specificity with :where()
Element selectors within `.article-prose` SHALL use `:where()` wrappers for child HTML tags.
Base element styles SHALL maintain zero selector specificity.
Nested widgets and React islands SHALL render their own styles without specificity conflicts.

#### Scenario: Rendering an interactive widget inside an MDX article
- **WHEN** an interactive React island renders inside `.article-prose`
- **THEN** article typography rules do not override the widget component styles

### Requirement: Typography uses fluid sizing and modern text wrapping
Body text line measure SHALL be constrained to a maximum of `70ch`.
Headings SHALL declare `text-wrap: balance` to balance line wraps across viewports.
Body paragraphs SHALL declare `text-wrap: pretty` to eliminate orphaned words.
Headings and vertical rhythm SHALL scale fluidly using `clamp()`, `rem`, and relative line units.

#### Scenario: Displaying article copy across responsive viewports
- **WHEN** article content renders across mobile, tablet, or desktop viewports
- **THEN** headings wrap with balanced lines and body text measure remains under 70ch

### Requirement: Syntax highlighting styles are isolated from prose rules
Shiki code blocks and preformatted elements SHALL be isolated from prose text and margin rules.
Code block styling SHALL NOT require `!important` resets in component wrappers.
Token colors generated by the syntax highlighter SHALL apply without style contamination.

#### Scenario: Rendering code blocks inside an article
- **WHEN** a Shiki code block renders inside an `.article-prose` container
- **THEN** code tokens preserve syntax colors and backgrounds without typography overrides
